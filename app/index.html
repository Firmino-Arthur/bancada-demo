Bancadado corretor

Primeiro passo

Escolha a pasta dos seus clientes.

Crie uma pasta chamada Bancada nos seus Documentos e escolha ela aqui. Os clientes ficam gravados nela, no seu computador, e o Claude Code trabalha na mesma pasta.

Este navegador não grava em pasta. Abra no Google Chrome ou no Microsoft Edge.

Bem vinda de volta

Liberar a pasta Bancada.

Por segurança, o navegador pede pra confirmar o acesso à pasta. É um clique.

Claude Code

Na pasta Bancada tem o arquivo abrir o Claude.bat. Dois cliques nele abrem o Claude Code já dentro da pasta. Cole uma conversa do WhatsApp, mande um áudio transcrito ou peça "cadastra a Maria, 62 anos, Santos": a tela atualiza sozinha.
